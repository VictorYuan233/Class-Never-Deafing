Class Never Deafing 使用指南

适用于 0.5.7 · Apple Silicon Mac · macOS 14 或更高版本

用一个悬浮窗同时看实时原文和译文，结束后自动保存双语文本。

首次使用 录制和切换语言 显示与隐藏字幕窗 字幕外观 选择模型 保存字幕 排查问题 诊断日志

首次使用

  1. 在 Finder 打开 Class Never Deafing.app。右键点击菜单栏的字幕气泡图标，选择倒数第二项「设置」。
  2. 在「OpenAI API」输入你自己的 OpenAI 项目 API Key，点「存入钥匙串」。如果钥匙串暂时不可用，可点「仅本次使用」，退出 App 后需要重新输入。
  3. 右键点击菜单栏图标，在「输入源」子菜单选择系统默认麦克风、已连接的耳机或外接麦克风，或者「系统声音（扬声器／耳机输出）」。播放中的线上课程可用「系统声音」。也可在设置的「音频输入」中选择。输入更改在下一次开始录制时生效。
  4. 点击开始图标。按 macOS 提示允许麦克风访问，或在「隐私与安全性 → 屏幕与系统音频录制」中允许系统声音访问。授予权限后，若 macOS 提示重启 App，请退出后重开。

录制和切换语言

  • 顶部一行包含左上角的关闭按钮、状态圆点、两个语言菜单、按秒计时、开始、暂停／继续、停止和置顶。绿色表示正在采音，橙色表示暂停，蓝色表示连接或收尾，红色表示出错。鼠标停留时可查看状态和按钮含义。
  • 源语言默认「自动检测」，目标语言默认「普通话（简体中文）」。录制中可直接点顶部菜单切换。源语言从下一段生效，目标语言用于下一次提交翻译的段落。
  • 字幕原文在上，译文在下。正常每一到两句翻译一次，连续讲话最多约 12 秒提交一次。暂停会冻结计时，继续时沿用当前课堂的字幕。关闭按钮可隐藏字幕窗。隐藏后转录和计时继续运行，仍可从菜单栏停止转写。

显示与隐藏字幕窗

右键点击菜单栏的气泡图标。「显示字幕窗」在「隐藏字幕窗」下方，即使窗口已经打开，也会将它带到最前。显示一次后，是否持续置顶仍由字幕窗上的图钉控制。

在「设置 → 快捷键」分别给「显示字幕窗」和「隐藏字幕窗」点击「录制快捷键」，再按下想用的组合。可用带 ⌘、⌥ 或 ⌃ 的组合，或单独使用功能键。按 Esc 可取消，也可点「清除」删除已设置的快捷键。快捷键在其他 App 中也能使用。

字幕外观

在设置的「原文字幕字体（如英文）」和「译文字幕字体（如中文）」中，可分别设置字号、字体样式、粗体、斜体和颜色。点对应的颜色色块选择，点「恢复自动颜色」可随字幕窗背景恢复自动配色。

「字幕窗」可调整背景颜色、透明度和置顶。新字幕会在接近底部时跟随滚动并预留一行，向上翻看时会保留当前位置。

选择模型

在「设置 → 模型」分别选择转写和翻译模型，下一次开始录制时生效。

  • 转写默认使用 GPT-Live-Transcribe。GPT-Transcribe 会在每段提交之后开始转写。
  • 翻译默认使用 GPT-6 Luna，也可选 GPT-6.1 Terra、GPT-6.1 Sol、GPT-6 Astra、GPT-5.4 mini 或 GPT-4.1 mini。
  • 要使用其他 OpenAI 文本模型，选「自定义」并填写完整模型 ID。模型需要支持 Responses API 的文本流式输出，你的 API 项目也需要具有该模型的访问权限。

保存字幕

点击停止后，App 收尾并自动写入一个 UTF-8 .txt。点字幕窗文件夹图标可在 Finder 中定位。也可从菜单栏选择「另存本节课文本」。

在「设置 → 保存」选择默认目录。首次默认使用 ~/Library/Application Support/课堂字幕/课堂记录/。导出保留原文和译文，未完成的译文会有标记。

排查问题

  • 钥匙串报错时，可以处理系统授权提示或解锁「登录」钥匙串后重试。读取等待约 10 秒会超时，也可以用停止按钮取消，再从设置选择「仅本次使用」。
  • 有声音但无字幕时，先确认是否选了正确的音频输入，再检查系统权限、网络和 API Key。
  • 原文有字但译文失败时，检查翻译模型 ID、项目权限和 OpenAI API 额度。改用项目可用的模型后，开始新一节录制。
  • 从菜单栏右键菜单的倒数第二项打开「设置」，滚动到设置底部可找到「使用指南」和「详情」。退出 App 请选右键菜单的最后一项「退出」。「详情」显示版本、构建号、系统要求和本版更新内容。

转写和翻译通过 OpenAI API 处理。所选输入的音频和待译文本会发往 OpenAI。App 在停止后保存双语文本，原始音频不会写入磁盘。

诊断日志

在「设置 → 诊断日志」点「在 Finder 中显示日志」。文件位于 ~/Library/Logs/Class Never Deafing/diagnostics.log，记录 App 启动、钥匙串等待、音频权限、连接和保存结果。排查时可根据点击开始的时间查看附近记录。

日志上限为 1 MiB。超过时，App 会删除最早的完整记录并保留最近的记录。日志不包含 API Key、音频、原文或译文。
