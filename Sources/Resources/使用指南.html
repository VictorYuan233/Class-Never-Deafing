Class Never Deafing 使用指南

适用于 1.0.8 · Apple Silicon Mac · macOS 14 或更高版本

用一个悬浮窗同时看实时原文和译文，结束后自动保存录音和双语文本。

首次使用 录制和切换语言 显示与隐藏字幕窗 字幕外观 调整分句 选择模型 保存字幕和录音 排查问题 诊断日志

首次使用

  1. 把浅薰衣草双气泡图标的 Class Never Deafing.app 拖到 Finder 的「应用程序」。按 ⌘ + 空格，搜索 Class Never Deafing 并打开。运行时可从 Dock 点图标唤回字幕窗。右键点击菜单栏的字幕气泡图标，选择倒数第二项「设置」。
  2. 在「设置 → 转写」和「设置 → 翻译」分别填写 API 地址和 API Key，选择模型，再点击各自的「测试」和「保存 Key」。API 地址留空时使用 https://api.openai.com/v1。升级到 0.9.0 后，两组 Key 需要重新输入一次。
  3. 右键点击菜单栏图标，在「输入源」子菜单选择系统默认麦克风、已连接的耳机或外接麦克风，或者「系统声音（扬声器／耳机输出）」。这台 Mac 播放的音频可用「系统声音」。在旁边的 iPad 等设备外放时，请用能听到外放的麦克风。也可在设置的「音频输入」中选择。输入更改在下一次开始录制时生效。
  4. 点击开始图标。选择麦克风时，按 macOS 提示允许访问麦克风。选择「系统声音」时，按提示允许录制系统音频即可。系统声音需要 macOS 14.2 或更高版本。

录制和切换语言

  • 顶部一行包含关闭按钮、状态圆点、语言菜单、计时、开始／暂停／继续、小旗、停止、停止并另存为和置顶。开始与继续显示播放图标，正在采音时同一按钮显示暂停。绿色表示正在采音，橙色表示暂停，蓝色表示连接或收尾，红色表示出错。
  • 源语言默认「自动检测」，目标语言默认「普通话（简体中文）」。录制中可直接点顶部菜单切换。源语言从下一段生效，目标语言用于下一次提交翻译的段落。
  • 使用默认的 GPT-Live-Transcribe 时，正在识别的原文会完整换行，可在字幕窗内滚动查看。等待上一段译文时，后续原文继续更新。各段定稿后，整段译文补在对应原文下方。
  • 听到值得回听的地方时，点停止按钮左边的小旗。标记成功后小旗会短暂变黄，随后恢复原样。每节课从标记 1 开始编号，时间按录音播放进度精确到秒。悬停小旗可查看最近一次标记的位置。
  • 暂停会冻结计时，继续时沿用当前课堂的字幕。关闭按钮可隐藏字幕窗。隐藏后转录和计时继续运行，仍可从菜单栏停止转写。
  • 在「设置 → 自动暂停」开启「无声时自动暂停」，可设定 1–120 分钟，默认时长为 5 分钟，开关默认关闭。达到无声时长后停止采音、音频发送和计时，已有字幕会保留，排队的译文仍可完成。点击「继续」恢复同一场转写。录制中开启功能或改时间时，无声时长从修改后开始计算。

显示与隐藏字幕窗

右键点击菜单栏的气泡图标。「显示字幕窗」在「隐藏字幕窗」下方，即使窗口已经打开，也会将它带到最前。显示一次后，是否持续置顶仍由字幕窗上的图钉控制。

在「设置 → 快捷键」分别给「显示字幕窗」和「隐藏字幕窗」点击「录制快捷键」，再按下想用的组合。可用带 ⌘、⌥ 或 ⌃ 的组合，或单独使用功能键。按 Esc 可取消，也可点「清除」删除已设置的快捷键。快捷键在其他 App 中也能使用。

字幕外观

在设置的「原文字幕字体（如英文）」和「译文字幕字体（如中文）」中，可分别设置字号、字体样式、粗体、斜体和颜色。点对应的颜色色块选择，点「恢复自动颜色」可随字幕窗背景恢复自动配色。

「字幕窗」可调整背景颜色、透明度和置顶。新字幕会在接近底部时跟随滚动并预留一行，向上翻看时会保留当前位置。

调整分句

在「设置 → 分句」拖动「每批翻译句数」滑块，可选 1–5 句，默认 1 句。设为 1 句可更早看到译文，设为多句时 App 会把完整句子合在一起翻译。录制中调整立即生效。减少句数时，已经等候的完整句子可以立即提交。

实时原文继续显示。App 按讲话顺序读取定稿标点，识别句号、问号和感叹号，并跳过小数和常见缩写中的点。英文条件从句或以 because 等词收尾时，会尝试接上下一个音频片段。译文补在对应原文下方。

遇到长停顿或停止录制时，App 会提交已积累的内容。持续讲话很久都没有可靠的句末标点时，会尽量在逗号等自然边界换段。

配置转写和翻译 API

设置中，「转写」和「翻译」位于「译文字幕字体」和「快捷键」之间。每组都有独立的 API 基础地址、Key 和模型。鼠标在控件上停留约半秒即可查看说明，测试结果和错误会直接显示。三个 API 下拉菜单用灰色「（默认）」标记 GPT-Live-Transcribe、Responses 和 GPT-6 Luna。请使用服务商给出的 HTTPS 基础地址，包含所需版本路径（例如 /v1）。更换地址后，需要为新地址重新输入并保存 Key。API 地址、接口、Key 和转写模型在下一次开始转写时生效。

沿用本节课的翻译地址和接口时，录制中可以调整翻译模型和 Fast。下一批进入翻译队列的字幕使用新配置，已经排队和正在生成的字幕沿用入队时的模型。自定义模型需填完整 ID，点「应用模型」或按回车，再进行测试。

「测试转写」发送内置英文音频，「测试翻译」发送固定句子。成功时显示「测试通过」，失败时显示错误详情。可以测试尚未保存的 Key，通过后仍需点击「保存 Key」。测试可能产生 API 费用。

  • 转写默认使用 GPT-Live-Transcribe。两个预设通过兼容的 Realtime 接口工作。「自定义」使用兼容的 audio/transcriptions 接口，每段音频提交后返回原文。
  • 翻译默认使用 GPT-6 Luna 和 Responses（/responses）。只提供聊天补全的兼容服务可选 Chat Completions（/chat/completions）。两种接口都支持本 App 的流式翻译，请以服务商和所选模型支持的接口为准。鼠标悬停在「翻译接口」可查看说明。
  • Fast 默认关闭。开启后，请求会附带 Fast 参数。具体支持情况及费用取决于服务商和模型。

保存字幕和录音

开始转写时会自动录下所选输入源。手动暂停或无声自动暂停期间停止录音，继续时接着录同一个文件。隐藏字幕窗后，录音和转写继续。

「设置 → 保存」默认开启「自动保存录音和字幕」。点击停止后，App 会在默认目录保存 .mp3 录音和同名的 UTF-8 .txt 双语字幕。若 MP3 编码失败，会保留 .wav 录音。只要采到了音频，即使没有可导出的字幕，也会保存录音。

点停止旁边带文件夹的方形按钮，选择「停止并另存为」。等待剩余内容处理完后，可在弹窗中指定位置和共同的文件名。自动保存开启时，默认目录也会保留一份。取消弹窗时，已经自动保存的文件照常保留。已有同名录音或字幕时，请更换名称。

关闭自动保存后，字幕仍会实时显示。普通停止或退出会清理临时录音，仍可主动选择「停止并另存为」。开关和保留天数从下一次开始转写时生效。保留天数设为 0 时无限期保留。填正整数后，每次自动保存时清理默认目录中超过该天数、符合自动命名格式的历史录音和字幕。

在「设置 → 保存」选择默认目录。首次默认使用 ~/Library/Application Support/课堂字幕/课堂记录/。请选择 Git 仓库之外的目录。若旧设置指向 Git 仓库，App 会改用本机默认目录。右键点击菜单栏的字幕气泡图标，可选「打开保存文件夹」进入默认目录，或选「在 Finder 中显示已保存文件」定位本次保存的文件。

自动保存和手动另存的双语文本都在每段原文前标注录音起始位置，例如 [00:01:23]。该段译文紧接在下一行。时间精确到秒，暂停时段不计入录音时间。未完成的译文会有标记。

双语文本顶部的「回听标记」列出所有标记，正文也会插入相应时间点，例如 [00:14:32] 标记 1。播放同名录音时，可跳到该时间。点小旗不会中断转写或翻译。

实时字幕窗显示最近 20 分钟的录制内容。较早但仍在转写、等待续句或可重试的段落也会保留。从菜单栏选择「查看本节课历史」，用「较早」「较新」每次浏览 100 段，「刷新」回到最新一页。停止后自动保存和手动另存都包含整节课。

开启自动保存时，定稿字幕会定期写入 ~/Library/Application Support/课堂字幕/字幕归档/。导出完整 TXT 后，开始下一节课或退出会清理该会话的临时归档。意外退出时已写入的归档会保留。关闭自动保存时，历史仅留在内存，仍可主动另存。

排查问题

  • API 不可用时，请先在对应设置区点击「测试」，检查基础地址、接口类型、模型 ID、Key 和项目权限。
  • 有声音但无字幕时，先确认是否选了正确的音频输入，再检查系统权限、网络和 API Key。升级后首次选择「系统声音」时，若 macOS 请求录制系统音频，请允许。已拒绝时可在「隐私与安全性 → 屏幕与系统音频录制」的仅系统音频列表中授权。
  • 实时转写返回空文本时，补识别会适度提高较轻音频的音量。如果声音很短且仍无文字，字幕窗会略过该段。连续未能转写的段落只显示一行「此段未能转写」。
  • 原文有字但译文失败时，检查翻译模型 ID、项目权限和 OpenAI API 额度。改用项目可用的模型后，开始新一节录制。
  • 从菜单栏右键菜单的倒数第二项打开「设置」，滚动到设置底部可找到「使用指南」和「关于」。退出 App 请选右键菜单的最后一项「退出」。「关于」显示版本、构建号、系统要求和本版更新内容。

用于转写的音频和待译文本会发往各自配置的服务。实时转写补识别会再次提交对应片段，可能产生额外转写费用。完整录音单独保存在本机。若所选目录无法写入，可从菜单栏选择「在 Finder 中显示已保存文件」，找到保留在「未归档录音」中的录音。

  • API 密钥在 ~/Library/Application Support/课堂字幕/API/ 加密保存。transcription.sealed 和 translation.sealed 是密文，local.key 是解密材料。请把三者都当作私密文件。
  • 偏好设置由 macOS 保存在 ~/Library/Preferences/com.classneverdeafing.captions.plist。它包含语言、模型、API 地址和保存目录等选项。
  • 课堂记录默认位于 ~/Library/Application Support/课堂字幕/课堂记录/。Git 仓库不能用作默认目录或另存位置。

诊断日志

「设置 → 诊断日志」中的「记录诊断日志」默认开启。关闭后立即停止记录，已有日志仍可查看。开关状态会在下次打开 App 时沿用。

在「设置 → 诊断日志」点「在 Finder 中显示日志」。文件位于 ~/Library/Logs/Class Never Deafing/diagnostics.log，记录 App 启动、音频权限、连接和保存结果。字幕滞后时，可查看分段停顿、音频发送等待、转写定稿、翻译排队和译文首字的耗时。空转写会记录该段的有声时长。耗时以毫秒计，输入音量每 10 秒汇总一次。

日志上限为 1 MiB。超过时，App 会删除最早的完整记录并保留最近的记录。日志不包含 API Key、音频、原文或译文。
